When to use it

On a managed object whose state the person did not choose and cannot press: a connected source, a shared brief, a draft. It answers "what is this thing doing" in one word, at the smallest size in the system.

It never carries the next move. On 3.5 the failed source has a tag, an alert line in words under its name, and its own retry button, and the tag is only the first of the three. A tag alone reports that something is wrong and nothing about what to do next, which the voice rules forbid.

States

No states, and that is a decision rather than an omission. A status tag is a label on an object. It cannot be hovered into a different state, focused or pressed, and a hover on it would promise an interaction that does not exist.

Four states are given to a component because it is interactive, not because a template has four cells. Faking one with a class the product does not carry (.is-hover) would be the same defect as an invented role.
