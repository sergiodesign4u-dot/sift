Icon slot

One shape at several sizes, and every size sizes its own glyph. That rule is not tidiness: the one slot in this system that forgot it took 300px of a 316px row and pushed a whole screen off a 360 viewport.

When to use it

Wherever a thing needs a mark that is not a person: a source channel, an empty state, a step in a sequence. In this product it is also the answer to a question the avatar refuses: where a SOURCE needs an identity, it gets a channel token rather than a face.

On the failed source row it does a quieter job that is worth naming. The slot keeps the channel icon and does NOT switch to an alert mark, because the row already says it three times, in the dashed tag, the alert line and the warning band above. A fourth signal would cost the one thing the slot is for: knowing at a glance which source this is.

States

No states, and that is a decision rather than an omission. A slot is a frame around a glyph. Where it sits inside something interactive, that thing carries the states.

Four states are given to a component because it is interactive, not because a template has four cells. Faking one with a class the product does not carry (.is-hover) would be the same defect as an invented role.
