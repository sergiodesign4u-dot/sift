How to use it

When

Where one item came from, as a line per fact, under a heading that names the subject: Provenance (5.0), Affected citation (5.1), Source detail (3.6).

Same list, two forms. Prose with a link when the fact leads somewhere (the theme the item supports); label then value when every line is a property of one object.

When not

  • For the customer's words: take the evidence snippet. The list holds facts about the words, not the words.
  • For a row that is itself a link to a thing: take the list row link.
