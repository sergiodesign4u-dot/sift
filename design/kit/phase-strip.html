How to use it

When

Where a process has phases the person should see before committing. Ingestion was a black box in the As-Is journey, and this strip is the answer in visual form: the phases are named before the person commits, so the wait has a shape.

When not

  • To make a phase pressable: it is information, not an action. The one action of a screen is a button.
  • To show the way back: that is the breadcrumb.
  • To mark the current phase with the accent: cyan is already spent on the one next move. The current phase steps up a surface and its text goes to primary ink.

Limits

Usage rules that name this component. Each is written once, on Architecture, the usage rules, with where it was taken from; this is the short copy.

  • R9. At most one .steps on a screen. Where it stands is not settled yet; that is a backlog row.
