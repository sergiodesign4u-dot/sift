How to use it

When

When the screen has one thing to tell the person that the rest of the screen does not. The tone is the claim: information is neutral, warning is amber, and error is red and reserved for a failure that blocks or destroys. A recoverable run failure is a warning, not an error, and that is why the sync error screen is amber.

When not

  • To report a recoverable failure in red: that is the warning tone. Red is for a failure that blocks or destroys.
  • To label an object: take a status tag. A notice is a sentence, not a word.
