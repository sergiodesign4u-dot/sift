Rank number

Attribute A4 in one line: a ranking claim is only quotable if the position is written down. The list is already in order, and the number is what lets somebody say "it is third" out loud in a meeting.

When to use it

Beside every item in an ordered list the product asks somebody to defend: the ranked themes on 2.0, the rows of a brief on 6.1, the key takeaways in the public document. On the composer it does a second job: the order of those rows IS the recommendation, so the number is the artifact rather than a decoration on it.

States

No states, and that is a decision rather than an omission. A rank is a printed fact about a position. It is not focusable and not pressable; the row around it is what a person acts on.

Four states are given to a component because it is interactive, not because a template has four cells. Faking one with a class the product does not carry (.is-hover) would be the same defect as an invented role.
