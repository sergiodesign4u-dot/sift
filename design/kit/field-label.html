When to use it

Above every field, in all five forms this product has. The hidden form is the one worth explaining: on 6.1 the brief title is typed at heading size where it will be read, so a visible label above it would name a thing that is already obviously named, and the label goes to a screen reader instead of the screen.

Rule and anti-rule

rule
Work email

Name above, example inside. Both survive the first keystroke, because only one of them is in the field.

anti-rule

The name inside the field. It disappears the moment somebody types, and a person checking their own answer has nothing left to check it against.

States

No states, and that is a decision rather than an omission. A label is text attached to a control. The control has the states; the label follows it and has none of its own.

Four states are given to a component because it is interactive, not because a template has four cells. Faking one with a class the product does not carry (.is-hover) would be the same defect as an invented role.
