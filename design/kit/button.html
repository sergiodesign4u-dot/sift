How to use it

When

Where the person acts. One filled button per screen, and it is the next move: the fourth design principle, one decision at a time, written as usage rule R1. Every other real action takes the outline.

The label is a verb and its object from voice/docs/microcopy.md: "Build brief", "Import 840 items". A count in a label tells the person what they are about to commit to.

When not

  • To go somewhere: take .link. A button acts, a link travels.
  • For "Clear filters": take .link--action, a text action with a control's target.
  • To make it wide: take .u-full, never a new variant.
  • For a bare "OK", an exclamation mark or "just": the voice rules forbid all three.

Limits

Usage rules that name this component. Each is written once, on Architecture, the usage rules, with where it was taken from; this is the short copy.

  • R1. At most one filled .btn visible on a screen; every other real action takes .btn--ghost. An action at rest and an action on selection are exclusive in CSS: a ticked theme card shows .selbar and hides .head-action. On 0.0 Home the count is per section.

Anatomy

Three zones, and two of them are optional. The label is not.

ZoneClass or elementRule
the box.btn, .btn--ghost, .btn--bare44px floor, 6px radius, the one easing. Shared by all three emphases; they part on ink and ground only

Axes, with the rule that chooses

AxisValuesThe rule that chooses
emphasisfill 67 · outline 33 · bare 4One filled button per screen, and it is the next move (usage rule R1). Two filled buttons on one screen is not a strong screen, it is a screen that has not decided
contentlabel 55 · icon plus label 12 · icon only 13A leading icon promises "acts here". Icon-only is for a control that repeats down a list, where a label would be read fifty times to say one thing
sizemedium 116 · large 11Size is given by the density of the place, never by the importance of the action. Large exists on 0.0 alone, which is the one screen read by somebody who has not decided to read it
widthnot an axis100% against auto is layout. A full-width button is the same button in a one-column container, and it takes .u-full from base.css

Every number is read from the rendered product rather than from the first declaration in the stylesheet. A class can carry two steps, and a cell that is true about the CSS and false about the screen is worse than an empty one, because it looks checked.
