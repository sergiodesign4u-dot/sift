Information Architecture - Detail Layer - July 2026

Structure

The node hub. Every Detail Layer node is a chip here, in two sections: Global elements and Pages. Click a chip to open that node's architecture page. The chips are fed by ia/_nav.js, the single node registry, so a new node appears here the moment it is registered, no re-sync by hand.

Detail Layer - Step 4

Block bank by page type

Where the composition of a page comes from. Before this existed, the node template said "content blocks: 1, 2, 3" and named no origin, so the composition was the median of everything a model has seen. Every block below traces to a job, a barrier from the CJM, or an SEO requirement; a block with no trace is not taken, and the reason is written down. Built per page TYPE, not per node: 39 nodes are 12 types. Source: ia/docs/blocks.md.
